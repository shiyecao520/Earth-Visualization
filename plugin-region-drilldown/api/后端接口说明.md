# OneEarth 后端数据接口说明

插件不规定后端技术，只要求通过一个 `dataProvider` 适配器返回标准区域对象。

推荐后端提供两个接口。

## 1. 获取某一层级的区域

```http
GET /api/regions?level=country&parentCode=
GET /api/regions?level=province&parentCode=CHN
GET /api/regions?level=city&parentCode=330000
```

响应：

```json
{
  "items": [
    {
      "code": "330000",
      "name": "浙江省",
      "level": "province",
      "parentCode": "CHN",
      "hasChildren": true,
      "childLevel": "city",
      "center": [120.15, 29.28],
      "bounds": [118.0, 27.0, 123.0, 31.5],
      "datasetCount": 286,
      "paperCount": 74
    }
  ]
}
```

## 2. 获取区域数量

```http
POST /api/region-counts
Content-Type: application/json
```

请求：

```json
{
  "level": "province",
  "parentCode": "CHN",
  "codes": ["330000", "440000", "510000"],
  "filters": {
    "theme": "气候变化"
  }
}
```

响应：

```json
{
  "counts": {
    "330000": { "datasetCount": 286, "paperCount": 74 },
    "440000": { "datasetCount": 352, "paperCount": 106 },
    "510000": { "datasetCount": 168, "paperCount": 49 }
  }
}
```

## 字段要求

| 字段 | 必填 | 说明 |
|---|---|---|
| `code` | 是 | 行政区唯一编码 |
| `name` | 是 | 展示名称 |
| `level` | 是 | `country`、`province`、`city` |
| `parentCode` | 是 | 上级行政区编码，全球层级为 `null` |
| `hasChildren` | 是 | 是否有下级 |
| `childLevel` | 否 | 下级层级，例如中国的 `country` 下级是 `province` |
| `center` | 是 | 圆心经纬度 `[经度, 纬度]` |
| `bounds` | 建议 | 相机范围 `[西, 南, 东, 北]` |
| `datasetCount` | 否 | 数据集数量，默认 0 |
| `paperCount` | 否 | 论文数量，默认 0 |

## 数据原则

- 行政区主数据、层级关系、边界和统计都在 OneEarth 后端维护。
- 前端插件只消费标准区域对象。
- 如果只展示圆圈，不需要下发完整边界 GeoJSON。
- 如果后续需要边界描边，建议单独提供边界接口或矢量瓦片。
