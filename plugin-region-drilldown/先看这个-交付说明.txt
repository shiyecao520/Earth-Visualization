行政区圆圈下钻前端插件

这个压缩包包含一个已经做好的前端功能：
点击地球上的圆圈，可以逐级下钻，并返回上一级。

====================
一、先看效果
====================
1. 打开 demo 文件夹。
2. Mac 双击“启动演示.command”。
3. Windows 双击“启动演示.bat”。
4. 浏览器会自动打开演示页面。

注意：演示使用少量模拟区域，只用于展示效果。

====================
二、交给 OneEarth 程序员时
====================
优先让程序员看：

1. 给OneEarth程序员的说明.md
2. docs/接入说明.md
3. api/后端接口说明.md
4. dist 文件夹
5. npm-package/oneearth-region-drilldown-1.0.0.tgz

前端程序员使用 dist 或 tgz 文件接入 OneEarth 现有的 Cesium 球。
后端程序员按照 api 文件夹中的说明提供行政区数据。

====================
三、这个插件负责什么
====================
它是一个独立前端插件，负责：
- 在地球上画行政区圆圈；
- 点击圆圈逐级下钻；
- 返回上一级；
- 根据中心点和范围移动相机；
- 显示数据集数量和论文数量。

它不负责：
- 保存行政区数据；
- 查数据库；
- 提供后端接口；
- 热力图；
- 数据集详情页。

行政区数据应由 OneEarth 后端提供。

====================
四、重要说明
====================
OneEarth 已经有 Cesium 地球时，插件应挂到这个现有地球上，
不要另外创建一个新的地球页面。

正式接入必须复用 OneEarth 的 Cesium Viewer。
