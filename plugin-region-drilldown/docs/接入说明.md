# 接入说明

## 1. 推荐架构

```text
OneEarth 页面
  └── 现有 Cesium Viewer
        └── Region Drilldown DataSource
              └── 从 OneEarth 后端读取行政区数据
```

插件与 OneEarth 共用同一个 Viewer、相机和图层系统，不额外创建 iframe，不创建第二个 Cesium 球。

## 2. ESM 接入

适合 Vite、Webpack、Rollup、React、Vue 等现代前端工程。

```js
import { createRegionDrilldown } from "@oneearth/region-drilldown";

const regionLayer = createRegionDrilldown(viewer, {
  dataProvider: oneEarthRegionProvider,
  initialLevel: "country",
  filters: {},
  showControls: true,
  onRegionClick(region) {
    console.log("点击区域", region);
  },
  onLevelChange(state) {
    console.log("层级变化", state);
  }
});
```

## 3. UMD 接入

适合没有模块构建工具、依赖 `window.Cesium` 的页面。

```html
<script src="./Cesium.js"></script>
<script src="./region-drilldown.umd.js"></script>
<script>
  const regionLayer = OneEarthRegionDrilldown.createRegionDrilldown(viewer, {
    dataProvider: oneEarthRegionProvider
  });
</script>
```

## 4. dataProvider 规范

### 4.1 listChildren

```js
async function listChildren({ level, parentCode, filters }) {
  return [
    {
      code: "CHN",
      name: "中国",
      level: "country",
      parentCode: null,
      hasChildren: true,
      childLevel: "province",
      center: [104.2, 35.0],
      bounds: [73.5, 18.0, 135.1, 53.6],
      datasetCount: 1832,
      paperCount: 396
    }
  ];
}
```

### 4.2 getCounts

`getCounts` 可选。如果区域对象中已经包含数量，可以不实现。

```js
async function getCounts({ level, parentCode, codes, filters }) {
  return {
    CHN: { datasetCount: 1832, paperCount: 396 }
  };
}
```

## 5. 控制接口

| 方法 | 作用 |
|---|---|
| `reload()` | 重新加载当前层级 |
| `goBack()` | 返回上一级 |
| `goHome()` | 返回全球 |
| `drillTo(code)` | 下钻到当前层级中指定编码 |
| `setFilters(filters)` | 更新筛选条件并刷新 |
| `setRegions(regions, meta)` | 宿主直接推送区域数据 |
| `setVisible(visible)` | 显示或隐藏 |
| `getState()` | 获取当前层级、路径和筛选条件 |
| `destroy()` | 销毁插件，不销毁 Viewer |

## 6. 事件

| 事件 | 含义 |
|---|---|
| `regionClick` | 任意区域被点击 |
| `regionSelect` | 点击没有下级区域的叶子区域 |
| `levelChange` | 下钻或返回后层级变化 |
| `dataChange` | 圆圈数据更新 |
| `loading` | 开始请求区域数据 |
| `error` | 区域数据加载失败 |

## 7. 行政边界说明

圆圈定位只需要 `center`，相机范围只需要 `bounds`。

以下功能才需要完整行政边界：

- 沿行政区边界描边
- 点击行政区域内任意位置命中
- 沿边界裁剪热力图

如果后续需要这些能力，建议后端提供按需边界接口或矢量瓦片，不要把完整边界数据打进前端插件。
