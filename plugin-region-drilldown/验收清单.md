# 验收清单

- [ ] 插件挂载到 OneEarth 现有 Cesium Viewer，没有创建第二个地球。
- [ ] 全球层级显示国家圆圈。
- [ ] 点击中国后显示省级圆圈。
- [ ] 点击浙江省、广东省或四川省后显示城市圆圈。
- [ ] 点击没有下级区域的圆圈只飞行定位，不继续下钻。
- [ ] 左上角“返回上一级”可用。
- [ ] 面包屑可以返回指定层级。
- [ ] 圆圈显示数据集数量和论文数量。
- [ ] 更新筛选条件后区域数量刷新。
- [ ] 页面卸载后圆圈、事件和插件界面全部移除。
- [ ] 插件销毁后 OneEarth 的 Cesium Viewer 仍然正常。
